# Небольшой набор для воспроизводимости

Это числовая проекция завершённого опыта `exp-20261122T090132972643Z-473911`: 15 книг, две обработки одного набора. Она подготовлена для будущего репозитория; проект ещё не опубликован.

- `records.csv`: 30 строк, ID и URL источников, исходная категория, тема метода, цена GBP, рейтинг, статус/fallback.
- `summary.json`: происхождение, контрольные суммы оригиналов, модели, счётчики, время и токены.
- `checksums.json`: SHA-256 двух файлов данных.
- `rebuild.py`: проверяет хеши/общий набор ID, строит CSV распределений, PNG и числовую сводку в `outputs/reproduced/`.

Нет полных описаний книг, HTML, аннотаций, сырых ответов модели и секретов. Назначение — воспроизвести числовые результаты и диаграмму категорий, а не распространить исходные тексты. Исходный сайт — учебный Books to Scrape; значения не характеризуют книжный рынок.

```bash
python reproducibility/rebuild.py
```

Команда работает без сети/ключа. Она **не выполняет LLM** и не измеряет точность. Результат отражает сохранённые ответы, включая 2 кеша и 5 локальных пауз. `processing_errors=5` в оригинальном старом отчёте не равен 5 API-ошибкам.

## Полное частное восстановление для демонстрации

Числовой набор не восстанавливает каталог с исходными описаниями. Для него используйте частную копию `outputs/backups/protected-473911-20261122T091613Z/` (ZIP + inventory.json), не добавляйте её в публичный Git.

1. Скопируйте код/fixtures/.streamlit/requirements-lock.txt в новую папку проекта на втором компьютере. Установите зависимости по README. Не копируйте .env, GeminiApiKey.txt или .venv.
2. Перенесите папку резервной копии. Проверьте **до распаковки**:

```bash
python scripts/verify_backup.py outputs/backups/protected-473911-20261122T091613Z
```

3. Откройте `experiment.zip` стандартным архиватором Windows и извлеките в корень **новой папки проекта**. В архиве уже есть `outputs/experiments/...` и два `outputs/runs/...`. Не распаковывайте поверх пользовательских изменений.
4. Проверьте восстановленные файлы:

```bash
python scripts/verify_backup.py outputs/backups/protected-473911-20261122T091613Z --root .
python -m streamlit run app.py
```

5. Оставьте «Только просмотр». Для каталога, сравнения и экспорта кеш и ключ не требуются. Рядом с ZIP отдельно сохранён `shared-cache.sqlite` с контрольной суммой в `cache_inventory.json`; это снимок общего кеша и журнала квот всех запусков. Скрипт проверки проверяет также его хеш. Для последующих новых запросов перенесите актуальный `outputs/gemini_cache.sqlite` из исходного проекта; резервную копию кеша можно использовать только если после её создания не было новых запросов. Не выполняйте новые запросы из демонстрационной копии без актуального журнала и проверки квоты.

Полное восстановление сохраняет прежние IDs, хеши, HTML, ответы, SQLite, графики, журналы и шаблоны. Перенос этих материалов предназначен для личной учебной демонстрации, а не автоматической публикации.
