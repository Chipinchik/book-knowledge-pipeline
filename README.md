# Каталог знаний

Локальное приложение для сбора сведений о книгах, нормализации, анализа и сравнения Rules с Google Gemini. Практическая часть курсовой по дисциплине «Анализ и визуализация данных».

Приложение открывает сохранённый эксперимент на 15 книгах в режиме **«Только просмотр»**. Интернет и API-ключ для демонстрации не нужны. Books to Scrape — учебный источник: его цены и рейтинги не описывают реальный книжный рынок.

## Запуск в Windows / Git Bash

```bash
cd /d/book_knowledge_pipeline
source .venv/Scripts/activate
python -m streamlit run app.py
```

Откройте http://127.0.0.1:8501. Остановка — Ctrl+C. Если порт занят, добавьте `--server.port 8505` и откройте соответствующий адрес. Сервер доступен только локально, телеметрия отключена.

На другом компьютере заранее установите Python 3.13 x64 и зависимости:

```bash
cd /d/book_knowledge_pipeline
py -3.13 -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements-lock.txt
python -m pytest -q
python -m streamlit run app.py
```

Не переносите старую `.venv`. Если псевдоним python Windows не работает, после создания окружения используйте `.venv/Scripts/python.exe`.

## Работа с приложением

[Руководство пользователя](USER_GUIDE.md) также доступно внутри приложения в разделе **«Помощь»**.

| Раздел | Что можно сделать |
|---|---|
| Главная | Посмотреть состояние выбранного эксперимента, сводные показатели и последние книги |
| Сбор данных | Собрать книги или просмотреть исходные записи; HTML и JSON сохраняются автоматически |
| Нормализация | Выбрать Rules / Gemini, выполнить или безопасно продолжить обработку |
| Каталог книг | Искать, фильтровать, сортировать; сравнивать исходное описание и результат |
| Аналитика | Посмотреть диаграммы и скачать PNG |
| Сравнение методов | Сравнить оба метода на одном снимке, увидеть ошибки, кеш, паузы и ручные оценки |
| Экспорт и эксперименты | Скачать CSV/JSON/SQLite, факты, журналы и материалы оценки |
| Помощь | Прочитать инструкции, разобраться с кешем и сообщениями об ошибках |

Выбор эксперимента и метода в боковой панели общий для всех разделов. Короткие проверки и исходные наборы скрыты под «Другие сохранённые наборы». Идентификаторы, хеши, параметры и журналы доступны в раскрываемых технических разделах.

Завершённый метод предлагается открыть, а не выполнить повторно. **«Новый эксперимент»** создаёт отдельный рабочий сценарий и не заменяет сохранённые результаты. Gemini требует явного подтверждения перед запуском или продолжением. Rules работает без сети на сохранённых или помеченных синтетических данных.

## Gemini: настройка только для новых запросов

Используется официальный OpenAI-compatible endpoint Google, модель по умолчанию `gemini-3.1-flash-lite`. Реальные ответы сохранены в завершённом пользовательском эксперименте; при продуктовой доработке агент новых запросов не выполнял.

Администратор создаёт `.env` по безопасному `.env.example`, не перезаписывая существующую конфигурацию. Ключ вводится только локально. Ранее раскрытый ключ необходимо отозвать и заменить до следующего обращения. `GeminiApiKey.txt` приложению не нужен.

| Переменная | Назначение |
|---|---|
| GEMINI_API_KEY | Секретный ключ |
| GEMINI_MODEL | Модель нового опыта |
| GEMINI_TIMEOUT | Таймаут HTTP в секундах |
| GEMINI_DELAY | Минимальная задержка между запросами |
| GEMINI_MAX_REQUESTS | Общий бюджет HTTP-попыток запуска, включая повторы |
| GEMINI_DAILY_LIMIT | Локальный предел за скользящие 24 часа |
| GEMINI_RETRIES | Ограниченное число повторов |
| GEMINI_MAX_OUTPUT_TOKENS | Бюджет ответа, 128–2048; 512 не гарантирует полный JSON |
| GEMINI_FREE_TIER_CONFIRMED | Заявление пользователя, не проверка квоты/тарифа |

Переменные окружения имеют приоритет над `.env`. Безопасные параметры фиксируются при подготовке пары; секрет не сохраняется. При продолжении нельзя подменять модель, снимок и размер ответа. Локальный бюджет можно явно увеличить с учётом уже выполненных попыток.

Бюджет проекта — 0. Перед новым запросом пользователь проверяет фактические RPM/TPM/RPD и отсутствие платного биллинга в своём AI Studio. Локальный журнал не знает о запросах из других программ. Приложение не подключает оплату и не проверяет остаток удалённой квоты. Ответы 429/503, ошибки JSON и сети обрабатываются явно; успешные и неопределённые запросы автоматически не повторяются. Fallback обозначается как замена правилами и не считается успехом Gemini.

## Архитектура

`app.py` — Streamlit и общий контекст просмотра. `coursework/scraper.py` — Books to Scrape, robots.txt, HTML и продолжение сбора. `normalize.py` — единая Pydantic-схема, Rules, проверка семантического JSON. `llm_provider.py` — Gemini, лимиты, повторы и кеш. `pipeline.py` / `experiments.py` — снимки, отдельные запуски методов и продолжение. `report.py` / `storage.py` — факты и экспорты. `dashboard.py` / `status.py` — чтение результатов и классификация событий. `visuals.py` — единые данные интерактивных диаграмм и PNG. `evaluation.py` — ручные оценки. `secrets.py` — безопасный аудит.

Исходные документы лежат в `outputs/experiments/<id>/`, результаты — в `outputs/runs/<id>/<method>/`. Запись содержит ID/название, исходную и нормализованную категории, цену/рейтинг, исходное описание, keywords/summary при наличии, URL, метод/модель, статус, fallback и IDs запуска/эксперимента. Факты сохраняют связь с книгой и URL. `outputs/gemini_cache.sqlite` хранит кеш и журнал квот; не очищайте его для повторной отправки.

## Проверки и CLI

```bash
python -m pytest -q
python -m coursework.secrets audit
# Автономная проверка правил на синтетических fixtures
python -m coursework.cli all --source demo --enrich rules --limit 10
# Новый сбор реальных страниц, без вызовов LLM
python -m coursework.cli scrape --source live --limit 15 --delay 1.5
# Воспроизведение числовой сводки без API и полных текстов
python reproducibility/rebuild.py
```

Научную пару удобнее готовить в интерфейсе. Demo и технические запуски не входят в статистику основного опыта.

## Перенос и подготовка к Git

Для личной офлайн-демонстрации перенесите код, `.streamlit`, `fixtures`, зависимости, `outputs/experiments`, связанные `outputs/runs` и кеш SQLite. Не переносите секреты, личные настройки и `.venv`. Можно восстановить только основной опыт из проверенного ZIP в **новую пустую папку**, сохранив структуру `outputs/...`; не распаковывайте поверх изменённых результатов. Проверку копии и восстановление описывает [reproducibility/README.md](reproducibility/README.md).

Для полностью автономной установки на таком же Windows/Python заранее подготовьте зависимости:

```bash
python -m pip download -r requirements-lock.txt -d wheelhouse
# На втором ноутбуке после создания окружения:
python -m pip install --no-index --find-links wheelhouse -r requirements-lock.txt
```

`.gitignore` исключает секреты, `.venv`, кеши, локальные настройки и всю `outputs/`. Для будущего репозитория подготовлена небольшая папка `reproducibility/`: числовые результаты и происхождение без полных описаний, HTML и ответов модели. Она воспроизводит сводку, но не заменяет частную резервную копию. Перед публикацией ещё раз выполните аудит. Удалённый репозиторий не создан, публикация не выполнялась.
